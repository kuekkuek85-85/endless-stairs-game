# PRD: 끝없는 계단 — 1학년 정보 캐주얼 게임 시리즈 #6

## 1. 개요
- **목적**: 1학년 정보 수업 사전 활동용 캐주얼 게임. 학습 요소는 드러내지 않고, 짧고 강한 "한 판 더!" 재미를 최우선으로 한다.
- **사용자**: 중학교 1학년 학생(주로 스마트폰, 태블릿·PC 병행), 교사(대시보드 확인)
- **기술 스택**: Vite + React, 게임 화면은 HTML5 Canvas, Firebase Firestore, GitHub 관리, Vercel 배포
- **한 줄 요약**: 지그재그로 끝없이 이어지는 계단을 버튼 두 개로 올라가며 최고 기록을 겨루고, 학번·성명으로 기록을 남겨 반·학년 랭킹을 본다.
- **저작권 주의**: 기존 상용 게임의 이름, 캐릭터, 그래픽, 효과음을 사용하지 않는다. 캐릭터와 그래픽은 모두 도형으로 직접 그린 오리지널로 만든다.

## 2. 화면 구성
1. **시작 화면**: 게임 제목 "끝없는 계단", 캐릭터 대기 애니메이션, 학번(5자리)·성명 입력, [게임 시작], [랭킹 보기], 조작법 한 줄 안내
2. **게임 화면**: 현재 계단 수(크게), 시간 게이지(상단 가로 막대), 개인 최고 기록, 일시정지 버튼, 하단 좌우 큰 버튼 2개
3. **게임 오버 화면**: 이번 기록, 최고 기록 갱신 여부("NEW BEST!"), 현재 전체·반 순위, [다시 하기], [랭킹 보기]
4. **랭킹 대시보드**: 전체 / 반별 탭, 상위 기록 목록

## 3. 로그인(학생 식별)
- 학번: 숫자 5자리 필수(예: `10305` = 1학년 3반 5번). 첫 자리 1, 반(2~3번째 자리) 01~15, 번호(4~5번째 자리) 01~40 범위로 검증
- 성명: 한글 2~5자
- 입력값은 localStorage에 저장해 다음 접속 시 자동 채움, [다른 사람으로 하기] 버튼 제공
- 별도 비밀번호 없음(수업용 간이 식별)

## 4. 게임 규칙
### 핵심 규칙
- 계단은 한 칸씩 위로 쌓이며, 각 계단은 이전 계단의 **왼쪽 위** 또는 **오른쪽 위**에 놓인다.
- 캐릭터는 현재 바라보는 방향이 있다(시작: 오른쪽).
- 버튼은 두 개뿐이다.
  - **[오르기]**: 바라보는 방향으로 한 칸 올라간다.
  - **[방향 전환]**: 몸을 반대로 돌리면서 동시에 그 방향으로 한 칸 올라간다.
- 다음 계단이 있는 쪽과 다른 방향으로 올라가면 **떨어져서 게임 오버**.
- 계단 한 칸 = 1점.

### 계단 생성
- 무작위 생성이되, 같은 방향이 최대 6~7칸 이상 연속되지 않게 한다.
- 초반 10칸은 방향 전환을 적게 넣어 워밍업 구간으로 만든다.
- 화면에 앞으로 올라갈 계단이 항상 최소 12칸 이상 보이도록 미리 생성하고, 지나간 계단은 메모리에서 제거한다.

### 시간 게이지
- 게이지가 계속 줄어들고, 0이 되면 게임 오버("시간 초과!").
- 한 칸 오를 때마다 게이지가 조금 회복된다(최대치 이상은 회복되지 않음).
- 기록이 오를수록 게이지 감소 속도가 빨라진다(예: 50·100·200·300칸마다 한 단계씩).
- 게이지가 30% 이하이면 막대가 빨간색으로 깜빡인다.

### 재미 요소
- **배경 변화**: 높이에 따라 배경이 바뀐다 — 0칸 학교 운동장 → 100칸 하늘·구름 → 300칸 노을 → 500칸 우주·별
- **마일스톤 연출**: 50칸마다 "50!" 같은 큰 숫자 팝업과 효과음
- **떨어지는 연출**: 틀리면 캐릭터가 빙글빙글 돌며 아래로 떨어지고 화면이 살짝 흔들린다.
- **캐릭터 색상 선택**: 시작 화면에서 5가지 색 중 선택(localStorage 저장). 캐릭터는 동그란 몸통 + 눈 + 짧은 다리의 단순한 오리지널 디자인.
- **효과음**: 오르기, 방향 전환, 마일스톤, 떨어짐(Web Audio로 직접 생성한 짧은 소리). 음소거 토글 제공, 설정은 localStorage 저장.

## 5. 조작
- **모바일·태블릿**: 화면 하단 왼쪽 = [방향 전환], 오른쪽 = [오르기]. 엄지로 누르기 좋게 크게(각 화면 폭의 약 45%).
- **PC**: `F` 또는 `←` = 방향 전환, `J` 또는 `→` = 오르기, 스페이스바 = 일시정지
- **반응 속도가 핵심**이므로:
  - `click`이 아닌 `pointerdown`/`touchstart`로 즉시 처리
  - 여러 손가락 빠른 연타(멀티터치) 모두 인식
  - 더블탭 확대, 길게 눌러 텍스트 선택, 스크롤을 모두 막음(`touch-action: none`, `user-select: none`)
  - 키보드를 누르고 있을 때 생기는 자동 반복 입력(`event.repeat`)은 무시
- 버튼을 누르면 살짝 눌리는 시각 피드백
- 탭 전환·화면 꺼짐 시 자동 일시정지

## 6. 기록 저장(Firebase Firestore)
### 컬렉션 구조
```
scores/{studentId}
  studentId: "10305"
  name: "홍길동"
  class: 3            // 학번에서 추출
  bestScore: 214      // 최고 계단 수
  playCount: 17
  updatedAt: serverTimestamp
```
- 판마다 문서를 새로 만들지 않고, 학생별 문서 1개를 갱신(쓰기 횟수 절약)
- 게임 오버 시: playCount +1, 최고 기록을 넘었을 때만 bestScore 갱신
- 저장 실패 시 "기록 저장에 실패했어요" 메시지와 [다시 시도] 버튼 표시

### 부정 기록 최소 방어
- Firestore 보안 규칙: studentId는 5자리 숫자, name은 1~10자 문자열, bestScore는 0 이상 3000 이하 정수만 허용, 문서 삭제 금지
- 클라이언트 검사: 한 판의 경과 시간 대비 계단 수가 사람이 누를 수 있는 속도(초당 약 12칸)를 넘으면 저장하지 않음

## 7. 랭킹 대시보드
- 탭: **전체 TOP 30** / **반별 TOP 10**(반 선택 드롭다운)
- 표시 항목: 순위, 학번 앞 3자리 + 성명(예: `103 홍길동`), 최고 계단 수, 플레이 횟수
- 1~3위 메달 아이콘, 본인 기록은 강조 표시
- 실시간 반영(onSnapshot) — 수업 중 화면에 띄워 두면 기록이 바로 올라감
- 교사용 큰 화면 보기 버튼(프로젝터용 글자 확대)

## 8. 비기능 요구사항
- 모바일 세로 화면 우선, 가로·PC에서도 게임 영역이 잘리지 않을 것
- 저사양 태블릿에서도 끊김 없는 60fps(requestAnimationFrame, 게임 로직과 렌더링 분리)
- 카메라는 캐릭터를 부드럽게 따라가며 캐릭터가 항상 화면 아래쪽 1/3 지점에 위치
- 첫 로딩 2초 이내, 외부 이미지 없이 캔버스 도형으로 그래픽 구성
- Firebase 설정값은 `.env`(VITE_ 접두어)로 관리해 GitHub에 커밋하지 않고, Vercel 환경변수에 등록

## 9. 폴더 구조(권장)

```
src/

  game/        engine.js (계단 생성·판정·게이지), renderer.js (캔버스·카메라·배경), input.js (터치·키보드)
  firebase/    config.js, scores.js

```

## 10. 완료 기준(체크리스트)
- [ ] 학번 형식이 틀리면 시작 불가, 안내 문구 표시
- [ ] 스마트폰에서 두 버튼을 빠르게 연타해도 입력이 빠짐없이 인식되고, 화면 확대·스크롤이 일어나지 않음
- [ ] 방향이 틀리면 즉시 떨어지고 게임 오버, 게이지가 0이 되어도 게임 오버
- [ ] 기록이 오를수록 게이지 감소가 빨라짐
- [ ] 높이에 따라 배경이 바뀌고 50칸마다 연출이 나옴
- [ ] 키보드를 누르고 있어도 계단이 자동으로 올라가지 않음
- [ ] 게임 오버 후 최고 기록만 갱신되고 playCount는 매번 증가
- [ ] 랭킹이 전체·반별로 올바르게 정렬되고 실시간 반영
- [ ] Vercel 배포 후 모바일 브라우저(크롬, 사파리, 삼성 인터넷)에서 확인
